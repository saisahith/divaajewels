# Divaa Jewels Shopify Theme

Shopify theme for Divaa Jewels N Ensemble.

## Local Development

```bash
shopify theme dev --store divaa-jewels-va.myshopify.com
```

## Validation

```bash
shopify theme check
```

## Deploy To Unpublished Theme

```bash
shopify theme push --store divaa-jewels-va.myshopify.com --unpublished --theme "Divaa Jewels V3"
```

## Notes

- Keep code changes in GitHub.
- Use Shopify Admin for products, collections, menus, payments, shipping, taxes, and store settings.
- Avoid direct live theme code edits in Shopify Admin unless the change is immediately pulled back into this repository.
